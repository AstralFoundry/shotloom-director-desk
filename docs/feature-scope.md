# 功能范围与已知限制

Shotloom Director Desk 是单场景三维预演工作台，工作流程为「搭场景 → 摆人物与道具 → 调姿态与机位 → 排运镜与动作 → 导出参考」。

## 保留

- 3D 场景：地面、白模人物/道具、自定义 GLB/glTF/FBX/OBJ 模型
- 场景列表、搜索、对象选择、显隐、变换（移动/旋转/缩放）
- 人物姿态、动作片段、相机机位、相机/人物路径
- 时间线：播放、定位、分割/时长、缩放、切镜与动作轨道
- 导演视角 / 机位视角切换
- 导出当前画面 PNG、导出运镜视频（MP4/WebM，按切镜或单机位）
- 自动备份与恢复；对象调色

## 已知缺口

- **手机运镜**：需要本地 Python 信令服务、HTTPS 证书与 WebRTC，尚未移植。
- **场景根变换 / 背景图片 / 全景背景 / 地面透明度与高度**：当前通过环境光、天空色、地面色和地面道具表达。

## 运行

```bash
npm install
npm run dev   # http://127.0.0.1:5173
npm run build
```
